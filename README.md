# Material

根据小红书分享链接，自动读取笔记详情，并将笔记内容喂给 LLM 生成分享文案的工具。

## 功能

- 解析小红书分享链接，提取笔记 ID
- 抓取笔记详情（标题、正文、图片、标签、互动数据等）
- 将笔记内容作为上下文喂给 LLM，生成适合二次传播的分享文案
- 输出可直接复制的文案结果

## 使用场景

- 内容运营快速产出二次分发文案
- 把小红书爆款笔记转化为公众号 / 朋友圈 / 微博等平台的素材
- 批量处理收藏的笔记链接，自动产出文案草稿

## 工作流程

```
小红书分享链接
     │
     ▼
解析链接，提取笔记 ID
     │
     ▼
请求笔记详情接口 / 解析页面
     │
     ▼
整理笔记内容（标题 + 正文 + 标签 + 图片描述）
     │
     ▼
调用 LLM 生成分享文案
     │
     ▼
输出文案
```

## 快速开始

### 环境要求

- Go 1.26+
- 可访问的 LLM API Key（如 OpenAI / DeepSeek / 通义千问等）

### 运行

```bash
go run main.go
```
